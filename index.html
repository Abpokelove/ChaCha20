So, what is ChaCha20? 🔐

It turns one secret key into an endless stream of random-looking bytes, then mixes that stream into your message so only the key holder can read it. Fast, simple, and quietly protecting your phone every day.

Under the hood ⚙️

ChaCha20 was designed by Daniel J. Bernstein as a faster, more mixed version of Salsa20 and is standardised in RFC 8439. It uses only addition, rotation and XOR, so it is quick even without special hardware.

Stream cipher

Encrypts byte by byte with a keystream, so any message length works and no padding is needed.

The 4×4 state

Sixteen 32-bit words: 4 constants, 8 key words, 1 counter and 3 nonce words.

Quarter-round

Four words are mixed with add, XOR and rotate. Four quarter-rounds make one round, and 20 rounds make one block.

Counter and nonce

The counter goes up by 1 for each 64-byte block. The nonce makes each message’s keystream different.

ADD +→ROTATE ⋘→XOR ⊕
Encrypt: Cᵢ = Pᵢ ⊕ Kᵢ  |  Decrypt: Pᵢ = Cᵢ ⊕ Kᵢ

Your 6-step mission 🚀

Six quick moves, from scrambling a message to shaking the whole cipher with a single flipped bit.

  1. Choose a modePick Encrypt to turn text into hex, or Decrypt to turn hex back into text.
  2. Enter message, key and nonceUse the Random buttons, or press “Load RFC 8439 vector” to use the official test data.
  3. Read the resultThe output updates as you type. Use “Use result as input” to run the reverse operation.
  4. Step through the roundsDrag the slider or press Play. Cells that flip changed in that round.
  5. Explore one quarter-roundPress Next to see each add, XOR and rotate on the words a, b, c and d.
  6. Try the avalanche testFlip one key bit and watch about half of the 512 keystream bits change.
